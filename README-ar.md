# تفوّق — إنجليزي الحادي عشر والتوجيهي

تطبيق ويب تقدّمي (PWA) يعمل دون إنترنت، يضم شرح قواعد المنهاج بالعربي، ومفردات كل وحدة مع النطق، وقطع القراءة (بالطريقة التقليدية وبوضع الاستماع والقصة المصوّرة)، وأسئلة وتدريبات ذكية، ونماذج كتابة، وامتحانات محاكاة بنمط الامتحان الوزاري، ومركز طباعة، ونسخ احتياطي لتقدّم الطالب.

---

## 1) تجربة النسخة على حاسوبك (خطوات التشغيل)

1. فكّ ضغط الملف `tafawuq-release.zip` في مجلد.
2. افتح نافذة الأوامر داخل المجلد وشغّل:

   ```
   python -m http.server 8080
   ```
   (وفي حزمة المصدر `tafawuq-source.zip` يمكنك بدلاً منه: `node tools/tests/serve.js 8080`)
3. افتح المتصفح على العنوان `http://localhost:8080`.

> لا تفتح `index.html` بالنقر المزدوج (عنوان `file://`)؛ العمل دون إنترنت والتثبيت كتطبيق يحتاجان إلى خادم.

**للتأكد أنك ترى آخر نسخة بعد كل تحديث:** اضغط `Ctrl+Shift+R`، أو من أدوات المطوّر: Application ← Service Workers ← Unregister ثم أعد تحميل الصفحة.

---

## 2) النشر على GitHub Pages (مثل بقية تطبيقاتك)

1. أنشئ مستودعاً عاماً باسم **`tafawuq`** في حسابك `haymohsen`.
   *اسم المستودع يجب أن يطابق المعرّف `id` في الملف `manifest.webmanifest` وقيمته `/tafawuq/`؛ وهذا يمنع تداخل التطبيق مع بقية تطبيقاتك على المضيف نفسه.*
2. ارفع **محتويات** المجلد (لا المجلد نفسه) إلى الفرع `main`، ومنها الملف المخفي `.nojekyll`.
3. من إعدادات المستودع: Settings ← Pages ← Deploy from a branch ← الفرع `main` والمجلد `/ (root)`.
4. بعد دقيقة أو اثنتين افتح `https://haymohsen.github.io/tafawuq/` وتحقق من التالي:
   - تظهر رسالة الترحيب (هايلي) في أول زيارة.
   - يظهر خيار التثبيت في المتصفح (أو زر «ثبّت» في صفحة الإعدادات).
   - بعد تصفح بعض الصفحات، افصل الإنترنت (وضع الطيران) وأعد فتح التطبيق: يجب أن يعمل كاملاً.
5. **عند أي تحديث لاحق:** استبدل الملفات بالنسخة الجديدة وارفعها. يتغيّر الملف `sw.js` تلقائياً مع كل بناء، فيظهر للطالب شريط «تحديث متاح» ويضغط عليه ليحمّل النسخة الجديدة، ولا يضيع تقدّمه.

## 3) حزمة متجر ويندوز (PWABuilder)

1. افتح موقع PWABuilder وألصق الرابط `https://haymohsen.github.io/tafawuq/` ثم اختر Package for stores ← Windows.
2. انسخ القيم من Partner Center (قسم Product identity بعد حجز الاسم):
   - **Package ID**: القيمة التي يعطيها المتجر لهذا التطبيق.
   - **Publisher ID**: `CN=73B709AB-BF94-4318-AE43-BAAA136F59D9`
   - **Publisher display name**: `Jotech`
3. اكتب رقم الإصدار (للإصدار الأول `1.0.0`)، **وارفعه في كل تحديث** كما تفعل مع بقية تطبيقاتك (الإصدار العادي وإصدار الحزمة الكلاسيكية).
4. نزّل الحزمة، وارفعها في Partner Center، وأدخل نص الصفحة من الملف `STORE-LISTING.md` (داخل `tafawuq-store-assets.zip` وحزمة المصدر).

**ملاحظات لنص صفحة المتجر:** الوصف نثر متصل (لا قوائم)، والميزات في حقل «Product features» المنفصل، وبلا أسماء علامات تجارية أخرى. النص الجاهز في `STORE-LISTING.md` يلتزم بذلك.

## 4) ما الذي في الحزم المرفقة

| الحزمة | الغرض |
|---|---|
| `tafawuq-release.zip` | **ما يُرفع إلى GitHub Pages**: الملفات التشغيلية فقط (التطبيق + المحتوى + الخطوط + الأيقونات + لقطات التثبيت)؛ وهذا الدليل ونص المتجر ليسا فيه عمداً |
| `tafawuq-source.zip` | **مشروع المصدر للصيانة**: ملفات الوحدات `data/units` والمواد الإضافية `data/extras`، وأدوات البناء والفحص `tools/`، وكل الاختبارات |
| `tafawuq-store-assets.zip` | لقطات الشاشة (1920×1080) ونص صفحة المتجر الجاهز لـ Partner Center |

داخل `tafawuq-release.zip`: `index.html` و`manifest.webmanifest` و`sw.js` (يُولَّد تلقائياً: التخزين دون إنترنت وإشعار التحديث) و`data/content.js` (كل الوحدات العشرين) و`js/` و`css/` (الواجهة والوضع الداكن والطباعة واستوديو القراءة) و`fonts/` (Readex Pro وLiterata بترخيص OFL) و`icons/` و`screenshots/`.

## 5) كيف يحفظ التطبيق تقدّم الطالب؟

- كل شيء محفوظ على جهاز الطالب (لا حسابات ولا خوادم).
- يحتفظ التطبيق بثلاث لقطات يومية احتياطية، ويستعيد تلقائياً من آخرها إن تلف الملف.
- من «المزيد ← بياناتك وتخزينها»: نسخة احتياطية (ملف JSON)، واستيراد (دمج أو استبدال)، وتصدير الكلمات المميّزة (CSV) والمسودات (TXT).
- لنقل التقدّم إلى جهاز آخر: صدّر النسخة الاحتياطية من الأول واستورِدها في الثاني.

## 6) للمطوّر: تعديل المحتوى وبناء نسخة جديدة (من حزمة المصدر)

```
npm install               # مرة واحدة: يثبّت أداة الاختبار (Playwright) إن أردت تشغيل الاختبارات
node tools/validate.js    # يفحص ملفات الوحدات (البنية، المفاتيح، الأسئلة)
node tools/build.js       # يجمّع الوحدات في data/content.js ويولّد sw.js
node tools/package.js     # ينتج مجلد tafawuq-release وملفات zip
node tools/screenshots.js # يعيد التقاط لقطات المتجر ولقطات نافذة التثبيت
npm test                  # بناء + فحص + تصحيح كل الأسئلة + اختبار ضغط الطباعة + اختبارات الواجهة
```

- ملفات الوحدات في `data/units/` (شكلها موثّق في `CONTENT_SCHEMA.md`)، والمواد الإضافية في `data/extras/`.
- بعد أي تعديل شغّل `node tools/build.js` قبل الرفع؛ ويُنصح بتشغيل `npm test` للتأكد من سلامة التصحيح والطباعة.
- ارفع رقم `version` في `package.json` قبل كل إصدار جديد.

## 7) أمور تستحق المراجعة قبل النشر

- **عنوان الوحدة الرابعة للصف الثاني عشر:** ورد في المصادر باسمين («Tastes» و«Inside story»)؛ اعتمدنا الأول، فتحقق منه في نسختك من الكتاب.
- **اختلاف طبعات الكتاب:** نصوص بعض مواد «مهارات الحياة» قد تختلف بين الطبعات؛ ما كتبناه نصوص مؤلَّفة خصيصاً للتطبيق وموافقة لموضوعات الوحدات.
- **مواصفات الامتحان:** مستمدة من الأوراق الوزارية المنشورة لعامي 2025 و2026، وتتغيّر أحياناً؛ ورقة «الإنجليزي المتقدم» لجيل 2009 غير معروفة بعد، وقد نبّه التطبيق الطالب إلى ذلك. حدّث ملف الامتحان `js/exam.js` عند صدور مواصفات جديدة.
- **الإخلاء من الانتساب:** صفحة «عن تفوّق» تبيّن أن التطبيق مستقل وغير تابع لأي جهة رسمية أو للناشر.
- **الدعم:** بريد الدعم الظاهر في التطبيق هو `haymohsen@gmail.com`، ويمكن تغييره من `TAF.config.support` في `js/core.js`.
