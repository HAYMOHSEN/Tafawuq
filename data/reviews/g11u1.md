# Review log — g11u1 "Get the message" (independent review)

Work copy: data/wip/g11u1.review.js (original untouched in data/units until the final `mv`).
Tooling note: validate.js insists that the file name equals the unit id, so the `.review.js` copy always shows one
"id must equal file name" error; the real validation was run on an identically named copy (0 errors, 0 warnings)
and is repeated on data/units/g11u1.js after the `mv`.

Method: every question (grammar 17+17, reading 10, test 20) was solved cold before looking at the key; every mcq
option was tested as a possible second answer; every gap/tr list was checked against the app's normaliser
(U.norm: expands n't/'m/'re/'ve/'ll, NOT 's/'d; ignores case, commas and final punctuation); every order item was
tested for a second natural arrangement of the same tokens; every English example and every Arabic translation
was read line by line; reading gist/tr/gloss were checked paragraph by paragraph; the model essay was counted.

### Grammar 1 — questions
- [major] qs[4] mcq "While I ____ to the radio, I heard my name" — "listened" is acceptable in a narrative while-clause, so a second option could be accepted → stem now "I ____ to the radio when I heard my name" (only "was listening" fits); x rewritten.
- [critical] qs[5] mcq "Your eyes are red. ____ at the screen all night?" — "Were you looking at the screen all night?" is perfectly natural when asked about the night just ended, so two options were defensible → stem now "… since breakfast?" and the weak distractor "Have you looked" replaced by "Had you been looking" (Did/Were/Had are all impossible with since); x rewritten.
- [critical] qs[6] mcq "How many messages ____ today?" — "have you been sending" is also acceptable English and "did you send" is natural for a finished day → replaced by "Sami ____ twelve messages since breakfast, and nobody has replied!" (has sent / has been sending / sent / sends; a number of completed items rules out the continuous); x rewritten.
- [critical] qs[9] gap "These days, more people ____ (use) …" — present simple "use" is equally natural with "these days", so the key rejected a correct answer → "At the moment, more people ____ (use) …" (one clear target: are using); x updated.
- [major] qs[10] gap "I ____ (wait) for your call for over an hour" — "have waited / 've waited" is correct English with "for over an hour" (and the unit's own tr item accepts both forms) but was not accepted → added have waited / 've waited / ve waited; x notes it.
- [major] qs[14] err "I have met him … last year" (w = have) — correction text "met (I met him …)" read as "replace have by met" (→ "met met") → c = "delete it (I met him at the conference last year)"; x explains the deletion.
- [critical] qs[15] err "She is knowing the answer …" (w = is) — not a one-word error: no single-token change corrects it ("is knowing" → "knows" needs two edits), so a student tapping "knowing" is equally right and would be marked wrong → replaced by a true one-token error "We have been friends since six years." (w = since → for); x rewritten. The state-verb rule stays in the tip box, Q3 and test Q7.

## Residual doubts
- App behaviour (not content): `U.closeMatch` tolerates one wrong letter in typed answers longer than 6 characters, so for gr2 qs[11] ("does she") a typed "does he" would be accepted as a "typo". Left as is; changing it would need the engine, not the unit.
- gr2 qs[5] (mcq, "There weren't many people …, ____?") — key "were there" is the standard rule; "were they" is heard in casual speech but is non-standard, so kept as a distractor.
- test[8] ("You ____ (paint), haven't you?") accepts only the present perfect continuous; "You have painted, haven't you?" is grammatical but a much weaker fit for "look at your hands", so it was deliberately not added.
- gr1 qs[9] still relies on "At the moment" to exclude present simple; a native speaker could stretch to "use", but it is clearly the marked choice.
- Scope: the unit teaches six present/past tenses; the past perfect is not covered (the title "Present and past tenses" could suggest it). Not added, to respect "no restyling"; the author may want a short box if the class textbook includes it.
- `topics` line mentions "تواصل الحيوانات" (animal communication), which appears in the unit only as one grammar example (bees); harmless but there is no reading/vocab on it.
- Mixed-gender student dialogue (Lina/Omar, school robotics club) — no romance and acceptable for the target audience; flagging only for the editor's awareness.
