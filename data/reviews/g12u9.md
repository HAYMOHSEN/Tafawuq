## Changes (1 critical, 2 major, 12 minor)

### Grammar 2 (would)
- [critical] qs[16] err "If I would have more free time, I could learn the oud." (w = would, c = had) — not a one-word error: the faulty
  unit is "would have" -> "had" (two tokens); applying c literally gives "If I had have …"; deleting only "would" gives a different but
  grammatical first-conditional sentence; a student tapping "have" would be marked wrong → replaced by a true one-token error
  "If I wouldn't live so far from school, I would walk there every day." (w = wouldn't, c = didn't; the second, correct "would" is a
  useful distractor); x rewritten.
- [major] qs[15] gap "I'd rather you ____ (not / tell) anyone about the surprise." — "hadn't told" (regret about the past) is equally
  possible with no time cue, but only "didn't tell" was accepted → added "until the party tomorrow" so that only the present/future
  reading survives; x now also states the past-perfect contrast.
- [minor] qs[7] tr (Ahmad said …) — the grader does not expand 'd; the apostrophe-less variant was listed only for "he'd" without "that" →
  added "Ahmad said that hed meet me at the station."
- [minor] warn "✗ Last summer we would go to Aqaba" — a native can read it as a habit within last summer (it only becomes wrong with a
  single occasion) → "Last Friday" (unambiguously one occasion), same rule.

### Grammar 3 (future continuous / perfect)
- [major] qs[14] tr "Next month it will be exactly five years since Hala started …" — a faithful transformation keeps "exactly"
  ("… for exactly five years") and the exact-match grader would reject it → "exactly" removed from the stem (answers unchanged).
- [minor] qs[1] gap "This time tomorrow I ____ (sit)" — first person: British "I shall be sitting" is correct but was rejected → added.
- [minor] qs[11] gap "we ____ (travel – future perfect continuous)" — "shall have been travelling/traveling" added for the same reason.
- [minor] qs[8] gap "I'll have finished the report ____ five o'clock." — key accepts by / before but x mentioned only "by" → x now says
  "before" is accepted too and why until is wrong.

### Grammar 1 (will)
- [minor] qs[7] gap "Don't worry, I ____ (will / not / tell)" — first person: "shall not tell" (and shan't, via U.norm) is correct BrE → added.
- [minor] final tip — said "shall" with I/we in offers is "formal" (it is ordinary British English in questions: Shall I …? Shall we …?
  while "I shall" in statements is the formal/old-fashioned use) → rewritten accordingly.
- [minor] trap paragraph — "ويُستثنى من ذلك أن تكون will …" is ungrammatical Arabic → "ويُستثنى من ذلك الحالة التي تكون فيها will …".

   by err qs[17] ("Yes, I'll." → "I will"), so the item was kept.

3. The will / must / might contrast tip ("will = assumption from habit or schedule, must = deduction from visible evidence") is a
   teaching simplification; native usage overlaps.
4. The reading title is identical to the textbook's reading title (the text itself is original); left for navigation. "Mirages … not tricks
   of the mind" is a simplification (the brain still misplaces the image) but matches the key of the "not tricks of the mind" item.
